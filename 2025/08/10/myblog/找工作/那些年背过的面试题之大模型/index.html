那些年背过的面试题之大模型

Posted on 2025-08-10 Edited on 2025-10-14 In 那些年背过的面试题 Views:

大模型基础

  • Transformer模型：Transformer 是基于自注意力机制的神经网络架构，摒弃了传统 RNN 的序列依赖，支持并行计算。它由编码器-解码器结构组成，广泛用于 NLP 任务。其核心包括多头注意力、位置编码和前馈网络，是 BERT、GPT 等大模型的基础。
  • 大模型微调：大模型微调是在预训练模型基础上，用特定领域数据继续训练以适配下游任务。相比从零训练，微调成本低、效果好，常用于分类、生成等场景。常用方法有全参数微调和参数高效微调（如 LoRA）。
  • 大模型架构：主流大模型多采用 Transformer 架构，分为 Decoder-only（如 GPT）、Encoder-only（如 BERT）和 Encoder-Decoder（如 T5）。结构上包含多层自注意力与前馈网络，规模扩展体现在层数、维度和专家数量上，MoE 成为高效扩展趋势。
  • 强化学习：强化学习通过智能体与环境交互，依据奖励信号优化策略。在大模型中，RLHF（基于人类反馈的强化学习）用于对齐语言模型输出与人类偏好，提升回答质量。典型应用如 ChatGPT 的训练后期阶段。
  • 大模型Agent：大模型 Agent 是能感知环境、规划决策、执行动作的智能体。它结合 LLM 作为“大脑”，通过工具调用、记忆管理和任务分解完成复杂任务，如自动编程、数据分析。体现从“问答”到“自主行动”的演进。
  • 大模型幻觉：幻觉指大模型生成看似合理但错误或虚构的内容。源于训练数据噪声和概率生成本质。影响可信度，尤其在事实敏感场景。缓解方法包括 RAG、微调、提示工程和推理时搜索验证。
  • LangChain：LangChain 是用于构建 LLM 应用的开源框架，支持链式调用、记忆管理、工具集成和数据连接。它简化了 Prompt 工程、RAG 和 Agent 开发流程，广泛应用于对话系统、文档问答等场景，提升开发效率。
  • MCP：MCP 就是一种通用标准协议，让不同的AI模型可以同标准、高效地调用各种各样的封装好工具。
  • RAG：RAG（检索增强生成）通过从外部知识库检索相关信息，辅助大模型生成更准确的回答。有效缓解幻觉问题，适用于动态知识场景。典型流程：用户提问 → 检索 → 拼接上下文 → 生成答案。
  • 大模型量化：量化将模型权重从高精度（如 FP32）转为低精度（如 INT8/INT4），减少显存占用和计算开销，提升推理速度。常见方法有 PTQ（后训练量化）和 QAT（量化感知训练），是大模型轻量化部署的关键技术。
  • 推理大模型和生成大模型：生成大模型注重文本、图片等内容的创作与生成，适合对话场景；推理大模型强调逻辑推断、因果分析和多步思考，适用于复杂问题、数学解题等高阶任务。生成模型侧重预训练大语料，明确上下文的“自然生成”。推理模型在训练/微调中强化“Chain of Thought（思维链）”、“Self-Consistency（自洽）”、“Step-by-step（步进式解析）”能力，常在微调数据或搭建特定的推理数据集上提升推理性能。

  • 模型GPT4_Turbo_128K_13B：128k指的是上下文长度，13B指的是130亿参数。Turbo：涡轮增压，表示速度和性能的提升。

  • prompt：提示词，旨在引导模型产生预期的输出或完成特定的任务。可以通过精心设计prompt来提高模型的性能和输出质量。

  • token：在大语言模型中指文本数据的基本处理单元，取决于分词方法tokenization，可以是一个词、一个字符。文本数据被输入到一个语言模型中时，首先被分解为一系列tokens。每个token随后被转换为模型能够理解的数值形式，通常是一个向量。

  • embedding工程：将词汇转变为能被机器处理的连续向量的技术，可以保持语义上相似的单词在向量空间中距离较近。简单来讲，就是向量化，嵌入工程。

  • 大模型预训练：基座预训练通常指利用无监督或自监督学习方法让模型学习到通用语言能力，这个过程往往需要利用大量语料以及大量的计算资源，然后在特定任务上进行微调。大模型预训练可以是有监督的，也可以是无监督的。有监督：使用已标注数据，例如图像领域的ResNet、VGGNet和自然语言处理的BERT早期。无监督：使用未标注数据，让模型捕捉数据的底层结构和分布，识别潜在模式和特征，包括自编码器、生成对抗网络（GANs）以及更近期的自监督学习方法，如BERT的后续版本和GPT系列模型。自监督：介于有监督和无监督之间，使用的是未标注数据，但是模型会自动生成伪标签或使用数据自身的一部分如掩码单词或图片的一部分作为监督信号来训练模型。

  • Bert模型：一种基于transformer的双向编码器，使用双向上下文信息，包括两个阶段：预训练和微调。预训练阶段通过两种无监督任务学习语言模型：1.掩码语言模型（预测被掩码的单词）2.下一句预测。微调阶段，进行端到端的监督训练。

  • GPT（Generative Pre-trained Transformer），即生成式预训练Transformer模型，主要关注生成任务，是一种基于Transformer架构的大规模预训练语言模型。分为两个阶段：预训练和微调，预训练使用无监督学习，预测下一个文本片段的出现概率，也叫自回归语言建模。微调使用监督学习。

  • GPT3中与传统微调不同，采用三种小样本学习方式，Zero-shot：给定任务描述，直接给出问题，要求模型给答案。One-shot，给定任务描述，然后给一个例子，包括问题和答案。Few-shot，与 One-shot 类似，只是给的示例更多。

  • 对话式GPT（ChatGpt），基于GPT架构，并利用多轮对话数据进行训练，同样采用了自回归语言模型，但在训练期间，它会对对话数据的上下文信息进行建模，以生成更符合实际对话场景的回复。预训练采用的是自回归语言模型（在大量无标注文本数据），即在给定上文的情况下，预测下一个词。微调阶段需要有标注数据，采用有监督学习和强化学习，通过强化学习，模型通过与环境的交互，得到反馈并不断调整。

  • 行业大模型的训练模式：开源大模型（ChatGLM系列模型、LLaMA系列模型等）+行业数据微调（Lora等）。

  • 训练数据：如果仅使用领域数据进行微调，容易导致模型的过拟合现象，会导致模型忘掉原有的能力。使用数据组合：通用领域数据+行业问答数据+行业专业文本。

  • 大模型微调三个阶段：1.监督微调SFT：使用标注数据监督微调预训练模型。2.奖励模型微调：同一问题的多个答案打分的数据集来训练奖励模型。3.基于人类反馈的强化学习RLHF：利用强化学习算法根据模型的奖励反馈进一步调优模型并与人类进行对齐。4.Prompt微调：试图通过学习语言模型来降低对大量监督数据集的需求。

  • Prompt工程：提示工程，可以认为是大型预训练模型（如GPT-3、BERT等）调参的一种形式，与传统的模型调整（比如更改网络层的参数或学习率）不同，它不修改模型内部的学习参数，而是聚焦于调整输入数据的表现形式，以期提高模型在特定任务上的表现。

  • 面向知识库的行业专属大模型：针对某个自有数据在原有大模型基础上调参，得到新的特定场景大模型。1.本地知识库构建：将文档和问答进行文本化处理和向量编码，结构化保存到向量库中。2.大模型推理：用户问题进行向量编码，从向量库中进行多阶段向量搜索得到top相关文本内容，结合历史记录，进行Prompt组装，利用大模型进行答案组装。3.大模型微调：如P-Tuning、LoRA等，基于自有数据微调出新的大模型，进行迭代替换。

  • 大模型部署：ChatGLM-6B：智谱AI和清华大学联合发布，开源的、支持中英双语的对话语言模型，基于 General Language Model (GLM) 架构，具有 62 亿参数。可在消费级显卡上进行本地部署，INT4量化级别只需要6GB显存。经过约 1T 标识符的中英双语训练，辅以监督微调、反馈自助、人类反馈强化学习等技术的加持。

  • git lfs：下载模型时使用到，large file storage，解决大文件版本控制和存储问题，将大文件存储在远程服务器上，Git仓库中保留指向这些文件的指针。

大模型训练

  • 预训练—后训练—推理的流程：预训练阶段，模型通过海量通用数据进行无监督或自监督学习，掌握基础知识和语言能力。后训练阶段，利用领域数据或用户任务对模型做微调或指令强化，提升在特定场景下的表现，如RLHF、参数高校微调LoRA。最终进入推理阶段，模型被部署，通过高效计算实现实际的输入到输出预测，服务真实应用需求。

  • RLHF和PPO：RLHF（基于人类反馈的强化学习）是大模型对齐人类偏好的核心技术。首先用人工标注数据训练奖励模型（Reward Model），学习对回复打分；然后通过强化学习优化语言模型，使其生成更符合人类喜好的内容。PPO（近端策略优化）是RLHF中常用的算法，它通过限制策略更新的幅度（使用裁剪机制），确保训练过程稳定。具体地，PPO基于新旧策略的概率比构造目标函数，结合优势估计进行优化，避免因更新过大导致性能崩溃。整个流程使模型从“能说”变为“说得更好”，广泛应用于ChatGPT等对话系统，提升输出的相关性、安全性和可读性。尽管效果显著，但RLHF训练复杂、成本高，现已有DPO等更高效方法出现。

  • DPO和PPO：DPO（Direct Preference Optimization）和PPO（Proximal Policy Optimization）都是用于大模型人类反馈对齐的算法，但原理和流程有所不同。

    PPO是一种强化学习策略优化方法，训练过程依赖奖励模型，由人类偏好数据训练出的奖励函数来引导生成模型通过试错方式提升输出质量。每次策略更新时，PPO通过“clip”策略限制模型改变幅度，保证训练稳定。

    DPO则直接基于人类偏好数据进行最优化，不需要先训练奖励模型。DPO将“人类偏好哪一个输出”转化为概率分布，并通过最大化偏好分数来直接优化生成模型，相比PPO结构更简洁，计算开销更低，避免了奖励模型拟合不准的问题。

    总体而言，DPO强化了算法的效率与对偏好数据的直接利用，是近年RLHF的重要替代方案。

  • PPO、GRPO、DPO：大模型人类偏好微调中的三种主流方法，PPO（近端策略优化）是基于强化学习的经典方法，通过奖励模型指导策略更新，但实现复杂且不稳定；DPO（直接偏好优化）摒弃强化学习框架，不用奖励模型，将偏好数据直接转化为损失函数，更简洁高效，正成为主流替代方案；GRPO（生成式奖励优化）近期提出，直接针对奖励模型优化生成结果，简化强化学习流程，提升效率。

  • 超长上下文是怎么实现的（例如 Kimi）：超长上下文能力（如Kimi大模型支持百万字级窗口），主要通过升级位置编码和注意力机制实现。首先，采用RoPE（旋转位置编码）等高效编码方法，让模型能准确区分和记忆极长序列中的词汇位置。其次，引入稀疏或分块注意力机制，如滑窗、局部自注意力、Chunk Attention等，避免全量计算带来的爆炸性内存和算力增长，大幅降低资源消耗。部分方案还结合高效缓存、分层处理和分布式计算，优化长文本的推理与存储。

  • 大模型训练原理

    • 预训练：数据来源（网页、书籍、新闻和代码等无标签数据）、训练范式（自监督训练，预测下一个词元）、目标（提升模型的语义语法理解和基础知识泛化能力）。
    • 免训练：进入免训练阶段，数据来源（少量样本和外部知识库）、训练范式（prompt工程（Few-Shot/CoT）和RAG）、目标（掌握特定领域知识）。
    • 后训练阶段：监督微调SFT：数据来源（业务数据、知识问答、人工标注和AI生成的有标签数据）、训练范式（监督微调SFT），目标是（获取特定领域知识）。强化学习：数据（偏好数据集（有标签））、训练范式（DPO/PPO算法，奖励、策略、价值和参考机制），使模型输出更符合人类偏好的内容，提升其有用性、安全性和价值观。逻辑推理能力：数据来源是CoT推理链。训练范式涉及CoT知识蒸馏、推理路径搜索和强化学习GRPO算法，目标是增强模型的深度思考能力。

  • prompt工程：明确任务指令，清晰定义任务的角色、背景、执行要求以及期望的输出格式，确保模型准确理解意图。引入示例引导：通过添加 One-Shot或 Few-Shot示例，提升对输入输出结构的理解与一致性。融入思维链CoT，在 Prompt 中引导模型分步骤推理，显式呈现思考过程，促使模型进行逻辑推导。

  • 强化学习：后训练阶段，提升模型的推理能力和对齐性，让智能体通过与环境的持续交互，在“尝试—反馈”的循环中学习最优策略，以最大化长期累积奖励。所谓“强化”，指的是当某个行为带来正向反馈（奖励）时，该行为在未来被选择的概率会增强；反之亦然。

  • 逻辑推理CoT训练：OpenAI的o系列模型出来之后，慢思考机制，构建长链条的思维过程CoT，可以分步求解、自我反思、错误回溯。数据来源为更强模型生成的具有逻辑结构和推理链的数据。训练方式：基于思维链的知识蒸馏，将强模型生成的高质量推理链作为“教师模型”的输出，指导“学生模型”学习其推理模式。

  • 监督微调：全参微调更新所有模型参数，效果好但资源消耗大。LoRA通过低秩矩阵近似权重变化，大幅减少可训练参数量，节省显存和计算成本。冻结原始权重，插入低秩适配模块，仅训练这些新增的小参数。关键参数：lora_rank（秩大小）、lora_alpha（缩放系数）。

  • 微调实战：利用强模型对部分样本进行高质量标注，在开源轻量模型上进行监督微调，利用 ModelScope 下载模型，Swift 框架进行微调。数据准备：大模型标注 → 人工校验 → 清洗转换 → 拆分为训练/验证/测试集。模型部署：上传至 OSS，通过 Omega 平台完成高效推理。

  • 量化：将较大尺寸的模型压缩为较小尺寸的方法。量化主要涉及对模型的权重参数和激活值进行量化。降低显存需要、提升推理性能。将权重值从较高精度如FP32映射到较低精度如FP16、BF16、INT8。线性量化方法：非对称线性量化、对称线性量化。

  • vllm：一个高效、轻量级的大语言模型推理与部署框架，专注于提升大模型在实际应用中的推理速度和资源利用率。vLLM采用PagedAttention技术，借鉴操作系统的虚拟内存和分页管理思想，优化了注意力机制中键值缓存（KV Cache）的存储与管理，显著降低了显存占用，提升了吞吐量。可将推理速度提升数倍，并支持更高并发请求。

  • Lora：大模型微调训练方法之一，大模型参数动辄10B，finetune对计算资源要求很高，需要上百G的显存。Lora的原理：大模型都是过参数化的，当用于特定任务时，只有一小部分参数起主要作用，可以用低维矩阵分解近似，思想与矩阵特征向量、主成分分析、压缩感知类似。具体做法：在网络中增加一个旁路结构，旁路相加，A（dr）和B（rd）两个矩阵相乘，旁路参数量远远小于原网络参数d*d，只训练旁路参数，训练时需要的显存开销大约为全参数finetune的1/3。LORA不改变原有的预训练参数，只是针对特定任务微调出新的少量参数，新参数与原有的预训练参数配合使用，参数相加，不增加推理时间，插件式应用。

  • nvidia-smi：用于监控和管理NVIDIA GPU的状态和性能。

  • 显卡、GPU、显存：1⃣️显存是一种特殊类型的内存，用于存储图形数据和纹理等与图像显示相关的数据，是图形存储器，具有高带宽低延迟的特点，可以快速读取和写入图像数据，以供GPU进行图形渲染和处理。2⃣️GPU是图形处理单元，专门用于处理图形和图像数据的处理器，是计算机图形渲染和加速的关键组件。GPU 负责执行图形渲染管线中的各个阶段，包括几何计算、光栅化、像素处理等，以生成最终的图像。设计重点在于并行处理能力，拥有成百上千的小核心，能够同时处理多个计算任务。3⃣️显卡：包含了GPU、显存（GPU专用的内存）、冷却系统（如风扇或水冷）、以及视频输出接口等多个组件。

  • N卡和A卡：N卡是NVIDIA公司生产的显卡，为了发挥N卡在并行计算的优势，NVIDIA开发了CUDA（Compute Unified Device Architecture）这一并行计算平台和编程模型。开发者可以使用C/C++开发软件程序来利用数以千计的核心并行处理数据。是许多机器学习框架（如TensorFlow、PyTorch）默认的GPU加速后端。A卡是AMD公司的显卡，AMD开发了自己的并行计算框架叫ROCm（Radeon Open Compute platform）。像CUDA一样，ROCm旨在提供一个充分利用GPU资源的并行计算环境。

  • torch.cuda.OOM：是PyTorch中常见错误，表示在执行CUDA时，内存空间不足以分配所需的内存。解决方法：1⃣️减小batch_size：batch_size 指的是单次前向传播和反向传播所处理的数据样本数量。减小batch_size可减少单次操作所需内存。2⃣️利用内存优化技术：Checkpointing (检查点)：在训练过程中，不保存所有中间变量，而是仅保存对最终结果有影响的关键张量，从而降低内存占用。DeepSpeed：一种深度学习优化库，它提供了自动内存管理和模型并行等功能，有助于更有效地利用 GPU 内存资源。3⃣️显存分配策略：在可能的情况下，可以尝试更精细地管理内存分配，例如在不需要使用某些张量时将其从 GPU 上卸载，或者在数据加载和预处理阶段采用更节省内存的方式。4⃣️使用更小的模型或调整模型结构。

大模型微调

  • 为什么要微调：大模型预训练，利用互联网海量语料对原始大模型进行训练，大模型具有了通用领域知识的解答和推理能力。但是：1.不能理解特定领域知识 2.私有数据不能泄漏。所以：大模型私有化部署后进行微调训练。

  • 微调PERT（Parameter Efficient Fine-Tuning）：对开源预训练模型的所有参数中的一小部分参数进行训练微调，最后输出的结果和全参数微调训练的效果接近。例如LoRA(Low-Rank Adaptation of Large Language Models)，可以将微调的参数在原来的全参数基础上减少10000倍，GPU资源降为原来的3倍，即对于千问72B模型，微调的参数从原来的720亿降为720万，GPU的显存资源也大大降低。

  • 大模型微调流程：开源预训练模型选型，数据集处理准备，微调训练SDK集成，训练参数设置，模型微调训练，微调模型验证，微调模型部署。因素：开源模型的参数大小、微调的库是否完善、数据集准备、模型运行需要的GPU资源是否能满足。

  • Lora微调参数：1⃣️batch_size:每次迭代（参数更新）中处理的数据样本数，在训练中每次前向传播和反向传播中使用的样本数量。神经网络训练中每次梯度更新所使用的样本数量。batch_size较大会导致GPU内存溢出。2⃣️ gradient_accumulation_steps：梯度累积步数，指在执行一次参数更新之前，应该累积多少个梯度步骤，在模型太大无法在一次前向和后向传播中处理足够大的批次数据时，避免内存限制，进行梯度累积之后更新参数。例如理想批次大小batch_size是16个样本，但由于显存限制最多只能处理4个，可以将梯度累积步数设置为4，意味着执行4次前向和后向传播，每次使用4个样本，然后将4次传播得到的梯度累积起来，一起进行一次参数更新。有效批次大小等于理想批次大小，同时避免超出内存限制。梯度累积有利于模型收敛和泛化。3⃣️template：表示使用哪种模版构造模型的输入。4⃣️train_iter:训练迭代的方式，表示模型训练的训练量。如果3epochs，表示模型将完整遍历三遍训练数据集，如果模型分为100个batch，则模型会进行300次迭代。如果100steps，模型将进行100次更新，无论覆盖了多少训练数据。epochs标准化数据遍历的次数，steps精细控制训练量。5⃣️compute_type：计算类型，指模型训练过程中使用的数值精度类型，影响模型训练的内存使用、计算速度。fp16是16-bit浮点数或半精度浮点数，相比fp32使用一半的位数表示数字，减少内存量，但是计算精度下降。bf16是Brain浮点数，是Google为深度学习推出的数值类型，和fp16一样使用16位存储长度，但是拥有与fp32相同范围的数值表示。减少内存的同时不牺牲太多精度，提高了数值稳定性。6⃣️随机种子seed：一种用于确定伪随机数生成器初始状态的数值，例如初始化模型权重、打乱训练数据集等操作具有随机性，使用确定的seed值可以控制在每次训练时都产生完全一样的随机数，确保训练流程的确定性和可复现性。random.seed(42)。7⃣️weight_decay：权重衰减，一种用于深度学习的正则化技术，主要用于减小不重要的参数对最终结果的影响，从而避免模型过拟合，类似于L2正则化对模型权重进行惩罚，通常会是一个小于1的正数，迫使模型学习到较小的权重值。8⃣️lora_target： 9⃣️lora_alpha：🔟lora_dropout：1⃣️1⃣️lora_rank：

  • checkpoint是什么：checkpoint是模型训练过程中的一个保存状态。包括模型参数、优化器状态、训练进度等信息。通过定期保存检查点，防止意外中断造成训练损失。

  • Dropout是什么：是一种用于防止神经网络过拟合的正则化技术，在训练过程中随机让一部分神经元的激活值变为0。阻止网络对任何单一神经元的过度依赖，仿佛在同时训练多个网络，并在测试时融合它们的效果。模型评估阶段，Droupout会被禁用，确保全面利用学习到的特征。

  • 随机数生成器random：使用相同的种子值时，随机数生成器将以完全相同的序列开始。基本原理是基于确定性的算法和初始种子值来生成看似随机的数字序列。种子表示第一个值，随后的每一个值都是根据一定的数学算法从前一个值计算出来的。

  • 微调训练数据优化：1⃣️针对SFT任务，通常1万条左右的精标数据可以发挥较好的效果。2⃣️数据质量比数据规模重要。3⃣️数据多样性。

  • ChatGPT原理：预处理文本：ChatGPT的输入文本需要进行预处理。输入编码：ChatGPT将经过预处理的文本输入到神经网络中进行编码处理，使用的是多层transformer编码器结构。预测输出：ChatGPT通过对输入进行逐个token预测，输出下一个最可能出现的token序列，使用的是softmax函数进行概率预测。 输出解码：ChatGPT将预测的token序列作为输入，经过多层transformer解码器结构进行解码处理，最终输出模型的回答。 重复步骤3和4：ChatGPT在处理输入时会持续输出预测的token序列，直到遇到停止符号或达到最大输出长度为止。

  • 预训练与微调：预训练是无监督或自监督的方式训练，使模型具有推理和生成能力。微调是使用有监督的方式使模型适应专业化领域场景。

大模型Agent

  • 大模型agent：Agent定义为能够感知环境、决策并执行动作的智能体，包含Brain（大脑）、Perception（感知）、Action（行动）三大模块，工作流程：感知环境→大脑处理→执行动作→反馈循环。

    Brain（大脑）：以LLM为核心，负责记忆、知识存储、推理和规划。

    Perception（感知）：扩展多模态输入（文本、视觉、听觉等），增强环境感知能力。

    Action（行动）：通过工具使用、具身动作（如机器人控制）与环境交互。

    agent分两类：

    人工流程编排类（Workflow Agent）：通过预定义代码路径协调LLM和工具的系统。

    自主规划类（Agent）：LLM动态指导自身流程和工具使用、自主控制任务执行方式的系统。（提示链、路由、并行化）

    都是基于通过检索、工具和记忆增强能力的LLM构建的体系。

  • 大模型幻觉如何解决：模型生成了缺乏事实依据、不准确或甚至捏造的信息。引入RAG结合外部知识库或数据库生成内容，提升事实性。进行微调，用事实性强的数据进行监督微调或偏好对齐（如DPO）。优化提示词，不确定时拒绝回答，思维链，输出思考过程。增加后置校验。

  • Agent实现：

    规划模块Planning：负责任务分解与决策，通过 Prompt 工程（如 ReAct、Chain-of-Thought）或微调实现推理能力；

    记忆模块Memory：短期记忆（上下文缓存）和长期记忆（向量数据库）用于存储与检索历史信息；

    工具调用模块Tool Use：集成外部 API（搜索、数据库、代码解释器），通过 Function Calling 实现与环境交互；

    执行引擎Action：控制流程调度，支持单步/多步执行、错误重试与循环监控。

  • Agent如何做决策：LLM Agent的决策过程主要依赖大模型的思维链推理和动态任务分解能力。接收到用户需求后，Agent通过预设Prompt引导模型将任务分为多个逻辑步骤，再依据当前上下文判断需要调用哪些工具或API，例如通过Function Calling协议选择具体工具并构造参数。每一步执行后，Agent会收集反馈结果，自主评估是否达成目标，必要时修正方案，实现动态调整。整个流程结合步步规划、状态记录和结果反思，让Agent能够自动完成复杂任务，提高智能自主性和实用性。常见实现结合LangChain、RAG等技术，将大模型推理与现实工具有效衔接。

  • 主流的Agent：

    LangChain：提供模块化工具，帮助构建 LLM 驱动的应用。支持链式调用、记忆管理、工具集成和数据连接。

    LlamaIndex（原 GPT Index）：主打数据与知识库检索增强，支持 Agent 调用外部文档、数据库及插件，适合构建知识检索型 Agent。可以与LangChain结合，用于增强 LangChain 的外部数据访问能力。

    OpenManus：一个基于Agent的自动化框架，具备规划、记忆、工具使用和行动能力。它通过多层继承结构实现智能体的核心功能，利用提示词驱动模型进行任务分解与工具调用，支持Web搜索、代码执行等操作。

  • 大模型Agent中的ReAct：ReAct是一种结合“推理（Reasoning）”与“行动（Acting）”的大模型Agent框架。让模型在任务执行中交替进行思考和操作。通过生成推理步骤指导下一步动作（如调用工具、查询信息），并根据反馈更新认知，提升决策准确性与可解释性，适用于问答、决策等复杂任务。

  • DeepResearch：深度研究AI智能体，是由 OpenAI 在 2025 年初推出的一种新型 AI “代理”（Agent），旨在自主完成深度研究任务，是 ChatGPT 中的一项强大功能。它基于最新的 o3 模型（GPT-4 系列的升级版），并通过端到端强化学习训练，具备多步骤推理与操作能力。具备自主规划与执行能力。强调“搜索 + 推理”的循环迭代。

  • 通义DeepResearch高阶Agent构建方法论：1、基于合成数据的持续预训练和后训练（一阶动作合成数据和高阶动作合成数据）。2、有监督微调（SFT）：使用高质量合成数据进行冷启动。3、强化学习（RL）：基于策略的组相对策略优化（GRPO），结合自动化数据引擎和稳定基础设施实现自我进化。4、推理ReAct模式：基于“思考-行动-观察”循环，无需提示工程即可展现强大能力。

  • DeepResearch Agent：传统聊天机器人缺乏主动探索信息与执行复杂任务的能力。相比之下，自主智能体（Autonomous Agent）则具备理解复杂意图、自主规划行动路径、调用外部工具、动态收集信息并进行深度推理的能力，从而输出更具洞察力与实用性的高质量答案。

  • LangChain：大模型 AI 应用开发框架，1. 组件化：抽象和封装了大模型领域常用的功能与模式，例如统一模型接口、提示词模板和上下文状态存储；2. 开箱即用：通过灵活的链式编排能力对上述原子组件进行结构化组装，以支持完成各式各样特定场景的高阶任务，例如私有知识库问答、结合外部工具的能力增强，以及自主决策行动的智能 Agent。仅支持Python和JavaScript。
  • LangChain本质上是一个基于LLM的应用程序开发框架，就像Spring一样，Spring是为了方便统一管理Java bean，提供拓展接口，简化程序开发流程，同样的，LangChain是将与LLM的交互通过定制化模块的方式，以链的方式进行管理，方便应用程序的开发，并同时提供了各种可拓展的方法，以实现对LLM的灵活调用。
  • LangChain中的模型包括：LLM、文本嵌入模型等，连续聊天、流式聊天。提示词模版化。输出结果结构化。数据连接组件，加载、转换、存储和查询数据，RAG：文档加载器、文档分割器、embedding模型（向量化）、知识检索。

Prompt

  • 提示词技巧：1⃣️结构化：提示词的本质就是通过语言将模型要做的事情交代清楚。角色+技能+限制。概述（角色+背景）、过程（技能+规则+流程）、依赖（工具+知识+素材）、控制（要求）。2⃣️加分隔符：在提示词中合理添加分隔符，区分指令和待处理的内容。例如 ```、— 、=== 等。3⃣️加示例。4⃣️加要求：发现 Bad Case 加入要求中，不断规范模型输出。5⃣️给出步骤：用来指导模型按照你的意图来输出信息。6⃣️自带知识库：对于非通用的知识，在提示词中给出知识库。采用检索增强生成技术（RAG），基于用户输入的信息通过内部或外部的搜索接口检索出相关信息作为背景知识拼接到提示词中传给模型。7⃣️重复提醒。8⃣️长提示词用户输入放最后。

  • 无论怎么优化提示词，效果都不理想：1⃣️单Agent：单轮对话如果效果不好，可以通过多轮对话完成任务。可以不断指出模型的问题，让他自己去纠正或优化。2⃣️换模型：专用模型。3⃣️多Agent协同：将复杂任务拆分成多个子任务，每个子任务通过一个 Agent 完成，然后通过多 Agent 协同。4⃣️人机协同：一些步骤让 Agent 完成，有些步骤让人工完成，或者 Agent 给出初版，人工二次优化或者人工进行审核。

  • 大模型幻觉问题：大模型生成看似准确但实际上虚假或无根据的信息。因为训练过程中学习到了复杂的模式，但缺乏真实世界的理解或验证能力。源于模型的目标是模仿训练数据中的语言模式，而不是追求事实的真实性或逻辑的准确性，导致产生误导性或完全错误的输出。

  • 大模型幻觉：1⃣️事实性幻觉：强调生成内容与可验证的现实世界事实之间的差异，通常表现为事实不一致或捏造。2⃣️忠实性幻觉：指生成内容与用户指示或输入提供的上下文的偏离，以及生成内容内部的自洽性。

  • 幻觉的原因：1⃣️训练数据有问题：内化了错误知识，例如“腾讯”经常会跟“游戏”一起出现，大模型可能将“原神”错误的认为是腾讯开发的。2⃣️训练过程有缺陷：预训练阶段：自注意力模式很难保持对每个token的关注，导致信息丢失。对齐微调阶段有缺陷：能力错位。3⃣️推理阶段的随机性：大模型在生成内容时依赖概率随机选择下一个单词或短语，序列化输出导致幻觉滚雪球。上下文关注不足。

  • 缓解大模型幻觉：1⃣️预训练阶段数据清洗。2⃣️SFT监督微调阶段，清洗训练数据，SFT数据中引入一些诚实的样本，即承认无能为力。3⃣️在RLHF人类反馈的强化学习阶段缓解，1）训练一个奖励模型（RW）作为人类偏好的代理，旨在为每个大模型的响应分配适当的奖励值；2）使用PPO等强化学习算法，利用奖励模型的反馈来优化SFT模型。利用人类反馈不仅缩小了机器生成的内容和人类偏好之间的差距，还有助于大模型与期望的标准或目标保持一致。强化学习可以指导大模型探索它们的知识边界，使它们能够拒绝回答超出它们能力范围的问题。4⃣️在推理阶段缓解，解码策略，如贪婪解码和束搜索解码，决定了我们如何从模型产生的概率分布中选择输出标记。或求助于外部知识：大模型通过广泛的预训练和微调，在其参数中内化了大量知识，这可以被称为参数知识。然而，不正确或过时的参数知识容易导致幻觉。为了解决这个问题，研究人员提出从可靠来源获取可靠、最新的知识，作为大模型的一种热补丁。这些知识的两个主要来源包括外部知识库和额外的工具。这种知识也称为上下文知识。5⃣️事后修正：构建一个辅助修正器，在后处理阶段修正幻觉。修正器可以是另一个大模型或一个特定的较小的模型。这些修正器首先与外部知识来源互动以收集足够的证据，然后纠正幻觉。6⃣️利用置信度：基于logit的估计、基于语言表达的估计。7⃣️多代理交互：从多智能体的角度来解决大模型的幻觉问题。8⃣️提示词：采用链式思维提示。

MCP

  • FunctionCall和MCP的区别：Function Calling 是大模型调用外部工具的技术，由模型判断是否调用、生成参数，并通过 API 返回结构化调用指令，需开发者手动集成每个工具的描述和代码，存在跨语言难、复用性差等问题。而 MCP（Model Context Protocol）是一种开放协议，采用客户端-服务器架构，通过标准化接口、数据格式和传输协议，实现工具与 AI 应用的解耦。MCP 支持通过配置自动发现并调用本地或远程工具，解决了 Function Calling 中的冗余开发和维护成本高问题。两者适用场景不同：Function Calling 适合轻量级应用，MCP 更适用于复杂、可扩展的工具生态体系。

  • MCP架构及工作原理：MCP是一种开放协议，旨在标准化AI应用与外部工具、数据源之间的连接方式，可类比为AI领域的USB-C接口。其核心采用客户端-服务器架构：MCPHost（如AI应用）通过MCPClient连接一个或多个MCPServer（提供工具服务的程序）。

  • MCP流程：MCPHost通过MCPClient向MCPServer请求工具列表、MCPServer返回可用工具列表、MCPHost将工具列表传给LLM、LLM判断是否需要调用工具，生成调用指令、MCPHost通过MCPClient向MCPServer执行工具调用、MCPServer执行工具并返回结果、MCPHost将结果传给LLM、LLM生成最终回复。

RAG

  • Rag中的向量数据库：外部知识库通过数据提取、文本分隔然后Embedding向量化之后，存储到特定的向量数据库中。用户提问时，RAG会利用文本向量化模型将用户问题进行向量化处理，然后再到向量数据库中进行向量查询，通过一定的算法得到Top K个相似结果，最后再结合prompt由大模型生成结果返回给用户。

  • 为什么要用RAG：大语言模型中，无法获取私域数据、缺乏特定领域知识、信息的准确性缺少、大模型可能会生成虚假内容。RAG无需针对特定任务重新训练，通过引入外部知识库的方式，解决问题。

  • RAG多路召回：向量检索+基于关键字的全文搜索，将全文检索和向量查询的结果进行融合排序得到Top k个结果。

  • RAG向量检索中的相似性度量：点积用于衡量两个向量的内积，值越大表示越相似；欧式距离反映向量间的绝对数值差异，距离越小越相似；余弦相似度则关注方向上的相对差异，取值范围为[-1, 1]，常用于文本和用户行为分析；而余弦距离是1减去余弦相似度，取值范围[0,2]，归一化后，欧式距离与余弦距离具有单调关系，此时两者检索效果相近。

  • 稠密向量和稀疏向量：稠密向量（多数元素非零）用数组或列表表示效率高、稀疏向量（多数元素为零）通过记录非零元素位置及对应值方式表达。

  • RAG向量索引：KNN最近邻算法通过全量计算实现高精度检索，但效率低；而ANN近似最近邻算法通过哈希、树、图等结构提升检索速度，适用于大规模数据。ANNOY基于二叉树划分空间，使用森林和优先队列提升召回率；LSH利用局部敏感哈希将相近向量映射至同一桶中，适合内存受限场景。

  • minhash与LSH：MinHash 用于高效估算大规模集合之间的 Jaccard 相似度。它通过对每个集合引入n个独立哈希函数，并记录每组下最小哈希值，形成n长度的签名向量。使用签名向量快速估算集合间相似度。LSH 局部敏感哈希，是一种空间划分技术，能把“相似”的对象高概率映射到同一个桶，“不相似”的对象落在不同桶，从而在大规模数据中高效查找近似邻居。对集合数据通常会结合 MinHash，把签名拆分分组，组内哈希入桶，快速筛出可能有相似集合的候选，再做精确度量。LSH 不要求精确查找，但大幅降低了高维空间下的检索复杂度。

  • RAG向量数据库：ADB阿里云推出的云原生向量仓库，具备全文与向量融合检索、实时索引构建。Lindorm是多模态云原生数据库，提供向量引擎，支持百亿级向量检索，可以自动完成文档切片和向量化。PGVector 是PostgreSQL的扩展。

Transformer

  • tranformers中的自注意力机制：Transformer 中的自注意力机制，就是让模型在处理每个词时，都能“环顾四周”去关注句子中与之相关的其他词。比如“小明喜欢苹果，因为它脆。”，处理“它”时，模型会自动把注意力集中在“苹果”上，从而理解指代关系。实现：首先，给每个词生成三个角色——Query（我想找谁）、Key（我能被谁找）和 Value（我有什么信息）。然后，用 Query 和所有 Key 匹配，算出一个相关性分数，再通过 softmax 转化为注意力权重，表示该关注谁。接着，按这些权重对所有 Value 加权求和，得到当前词融合上下文后的新表示。为了让模型从不同角度理解语言，还引入“多头注意力”——多个小组同时工作，有的关注语法，有的关注语义，最后把结果合并。整个过程可并行计算，高效且强大，使模型能捕捉长距离依赖和复杂结构。总之，自注意力让模型学会“哪里重要就看哪里”，是 Transformer 理解语言的核心智慧。

  • softmax：将一组数值转换成概率分布（0-1之间），并且所有结果加起来正好等于 1。在 Transformer 的自注意力机制中，Softmax 用来处理“Query 和 Key 的匹配得分”，把它变成注意力权重。

  • Transformer的Encoder和Decoder：Transformer的Encoder用于理解输入序列，通过多层自注意力和前馈网络提取上下文特征，输出隐藏表示。Decoder用于生成输出序列，不仅有自注意力，还通过“交互注意力”利用Encoder的输出，每次生成一个新词，并只能看到已生成内容（自回归）。简言之：Encoder负责编码理解输入，捕捉上下文关系，Decoder负责结合编码结果生成输出。只有 Encoder：用于理解类任务，如文本分类、情感分析（代表：BERT）；只有 Decoder：用于生成类任务，如写文章、聊天（代表：GPT）；Encoder + Decoder：用于“输入→输出”任务，如机器翻译、摘要生成（代表：原始 Transformer、T5）。

  • Transformer的Encoder和Decoder结构差异：1、Encoder全连接自注意力（双向），每个词可以关注前后所有词，Decoder掩码自注意力，只能关注当前及之前的词。2、Decoder额外有一层 Encoder-Decoder Attention，关注 Encoder 输出的 Key/Value。

  • Transformer中的FFN前馈神经网络：Encoder和Decoder的关键组成部分，和自注意力机制共同构成模型核心结构。FFN是一个简单的两层全连接神经网络，本质上就是一个“升维 → 激活 → 降维”的小型神经网络，做两次线性变换，先对词向量做一次‘升维扩展’（变大、更有表现力），再通过激活函数比如ReLU（引入非线性，让模型能拟合更复杂的特征），最后再降维（回到原始维度）。FFN(x) = Linear2(ReLU(Linear1(x)))。为什么升维：让每个词向量单独获得更多“表达空间”和复杂度。

  • Transformer中FFN的作用：1、引入非线性变换（自注意力主要是加权求和接近线性，FFN引入非线性，让模型能拟合更复杂函数）。2、FFN对注意力聚合后的信息进行深加工，提取更高层语义。3、FFN 对序列中每一个位置的向量单独处理（不跨位置），与“全局关注”的自注意力形成互补。总结：FFN 是 Transformer 中对每个位置进行独立深度处理的“思考模块”，它和“注意力”配合，让模型既能关注上下文，又能深入理解信息。

  • 激活函数：引入非线性，让网络能学习和表达复杂的、不是简单加减乘除能描述的规律。如果网络没有激活函数，只是一堆线性运算，不管加多少层，最后都等价于一层线性变换，模型能力很有限，不能拟合曲线。

  • 常用激活函数：ReLU：max(0, x) 把负数变0，正数保留 → 快速、常用。Sigmoid：1/(1+e^-x) 输出01，适合概率。Tanh双曲正切函数：-11之间S形曲线 更强的归一化。

机器学习基础

  • 机器学习开发流程：获取数据-数据预处理-特征工程-机器学习算法与训练-模型评估-应用。
  • 机器学习特征工程：特征抽取、特征预处理、特征降维。1⃣️特征抽取：数据转化为可用于机器学习的数字特征，特征值化，有字典特征提取、文本特征提取（jieba分词）、图像特征提取。2⃣️特征预处理：无量纲化：归一化、标准化。3⃣️特征降维：删除低方差特征，主成分分析PCA：数据维数压缩，损失少量信息。
  • sklearn：scikit-learn，用于机器学习的python库，建立在numpy(用于数值计算)、scipy(更丰富的数学工具库)、Matplotlib(用于数据可视化)基础上，提供了分类、回归、聚类、降维等工具和算法。提供机器学习算法实现：线性回归、逻辑回归、决策树、随机森林、支持向量机、K近邻算法、朴素贝叶斯算法、神经网络等。scikit-learn中，转换器（Transformers）和预估器（Estimators）是两个核心概念。转换器用于数据预处理和特征工程：标准化、onehot编码、PCA等。预估器用于模型生成、预测、评估。
  • KNN：K近邻算法，监督学习。对新样本进行分类或预测时，KNN会计算这个样本与其他所有样本之间的距离。找到最近的K个邻居，其中最多的类别作为预测结果。简单易于理解。计算量大内存开销大，适合小样本。
  • 朴素贝叶斯算法：一种基于贝叶斯定理和假设特征独立（朴素）的简单概率分类器。适用于文本分类。利用贝叶斯定理计算每个类的后验概率，即给定特征后，样本属于各个类的概率。p(c|w) = [p(w|c)p(c)]/p(w)。w为特征值，c为目标值。优势：对大数据集的高效性，通过简单概率计算快速训练和预测，计算需求低。特征独立要求高。
  • 决策树：基于树状结构进行决策的算法，训练阶段通过使用特征的不同取值划分训练数据集，通过计算划分的信息增益（知道哪个特征后，不确定性减少的量）来选择最佳划分点（先看哪个特征再看哪个特征）。通过递归地划分数据，决策树构建了一个树状结构，其中每个内部节点表示一个特征，每个叶节点表示一个类别或一个回归值。优点：简单，树木可视化，是个白盒。缺点：容易出现过拟合。
  • 随机森林：随机森林是一种集成学习算法，通过构建和组合多个决策树来提高模型的准确性和泛化能力。它使用自助采样（Bootstrap Sampling）来创建不同的数据子集，并在决策树的每个分裂点随机选择一部分特征来增加随机性和模型的多样性。虽然随机森林模型解释性较差，但在分类和回归任务中通常具有较高的预测准确率，并且相对其他算法对超参数不太敏感，易于使用。训练集随机和特征随机，它通过对训练数据进行有放回的随机抽样和特征的随机选择来构建多个决策树。应用场景：高纬度特征大数据场景。
  • 线性回归：基于线性假设，假设特征值和目标值之间存在线性关系，模型通过拟合一条直线（或超平面）来预测输出变量的值。线性回归模型可以视为神经网络的一种特殊情况，即只有一个神经元且没有隐藏层的神经网络（单层感知机）。
  • 梯度下降法(GD，Gradient Descent)：梯度下降法是一种寻找函数（损失函数）局部最小值的优化算法，通过计算函数的梯度（即导数）来确定下降的方向。在每次迭代中，参数沿负梯度方向更新，步长由学习率决定，以逐步接近目标函数的最小值。
  • 随机梯度下降SGD和随机平均梯度法SAG：1⃣️随机梯度下降每次迭代使用一个或一小批样本来近似计算梯度，减少对计算资源的需求，但更新过程比较嘈杂。2⃣️随机平均梯度法在每次迭代中，仅计算数据集中一个样本的梯度，但同时累积历史所有样本的梯度均值来更新参数，以此提升梯度估计的稳定性，并加快了收敛速度。
  • 过拟合和欠拟合：1⃣️过拟合：训练集上表现得好，测试集上表现不好，模型过于复杂，泛化能力比较差。2⃣️欠拟合：学习到的特征太少，模型过于简单，不能准确识别，应该增加数据的特征数量。
  • 正则化：机器学习中用于解决过拟合问题的方法，通过在损失函数中加入一个额外的惩罚项来限制模型复杂度，来惩罚模型参数的大小，减小高次项特征的影响，从而提升模型泛化能力。不仅让损失变小，还让权重系数变小。正则化项通常是模型参数的范数，L1正则化（也称lasso回归，添加了权重绝对值的和作为惩罚项）和L2正则化（也称岭回归，添加了权重平方的和作为惩罚项）。
  • 范数：数学中衡量向量大小的函数，向量空间中给定向量的“长度”或“大小”。L1范数（向量中各元素绝对值的和）和L2范数（欧几里得距离，向量中各元素平方和的平方根）和无穷范数（元素绝对值的最大值）。范数用于正则化和其他优化问题中，以控制参数的复杂度，防止过拟合，同时表征向量空间中的距离。
  • 准确率和召回率：准确率是预测正确的比例。召回率是查全率，正确预测为正例数/全部实际为正例数。为什么召回重要：查癌症，癌症为正例，10000个人里10人癌症。查出来九个，准确率是100，但是有一个癌症没查出来，召回就是90，是不行的。
  • 逻辑回归：一种用于解决二分类问题的机器学习算法。通过应用Sigmoid函数（或Logit函数）将线性回归的结果映射到0和1之间，以此预测样本属于某类的概率。
  • 无监督学习K-means：用于将一组数据点划分为K个不同的簇，以使每个点与其所属簇的中心（即质心）之间的距离之和最小。算法从随机选择的中心开始，通过迭代优化中心位置，直到满足收敛条件，如簇分配不再改变或达到预定迭代次数。

神经网络

  • 梯度下降算法：用于在线性回归中求损失函数的极小值。一阶函数里梯度表示某一函数在该点处的导数。梯度是一个向量，有方向，梯度的方向是函数在给定点上升最快的方向，梯度的反方向就是下降最快的方向。沿着负梯度方向一直走，就能走到局部的最低点。
  • 从线性回归到神经网络：神经网络图中的节点连线表示模型参数/模型权重。输入层之后的所有节点表示经过各层矩阵变换后的中间结果。
  • 卷积操作：一个函数翻转并平移后与另一个函数的乘积的积分。是一个对平移量的函数。卷积四要素：翻转、平移、乘积、叠加。现实中的意义：两枚骰子同时丢，点数加起来为几的概率，就可以用卷积来表示，就是多种情况的概率乘积再求和。矩阵的卷积：和一维数据一样，把卷积模版翻转180度，然后从上到下，从左到右滑动模版，计算乘积求和，得到的即为卷积后的数值。根据被卷积矩阵和卷积核的步长和相交方式，生成矩阵的大小也不同。矩阵卷积的举例：对图像高频噪点做平滑操作。
  • CNN中的核函数：也叫滤波器、卷积核。卷积操作是将核函数按照一定的步长和填充方式在输入图像上滑动，并计算每个位置上的卷积结果。总结起来，核函数是CNN中用于提取图像特征的一种操作，通过与输入图像的卷积操作来计算特征响应。核函数的参数通过训练来学习，可以逐层提取更加抽象的特征，从而实现图像的分类、识别等任务。
  • 卷积核的两个重要参数：步长（stride）和边距模式（padding模式）。步长描述卷积核每执行一次卷积后移动的距离，边距模式描述的是卷积核在遇到特征图边界时的处理方式。
  • CNN中的卷积层：对图片做特征提取，将特征矩阵化、数字化。每个卷积层包含多个核函数，用于学习到不同的特征。通过堆叠多个卷积层，CNN可以逐层提取更加抽象、高级的特征。一般来说，较早的卷积层会学习到一些基础的特征，如边缘、线条等，而较深的卷积层则会学习到更加复杂和抽象的特征，如纹理、形状等。
  • CNN的理解：卷积-池化-打平-全连接。卷积的本质是将整体缩小为局部看特征，就像拿着放大镜贴近目标去一点点仔细看。卷积核越小，取到的特征越精细。池化是对于一个局部，取出其最显著的特征值，例如最大化的取值法，抛弃其余，从而大大降低计算成本。打平+全链接的本质是，将所有的特征，通过加权，最终作用于图片分类的业务场景。总之，CNN最核心的还是卷积的理念，就是从局部去发现细微的特征。
  • CNN中的通道：RGB本来是三通道的，如果用两个卷积核，就变成六通道的。相当于对于同一个局部，拿很多个不同种类的放大镜去看。通道的数量越多，从深度上对特征的扩充越多。
  • RNN循环神经网络：多用于文本处理，需要做各种分词、embedding编码。RNN的本质：1⃣️处理序列数据时，RNN会考虑当前元素和前面元素的信息，通过将前一个时间步的隐藏状态作为当前时间步的输入来实现。能够记住先前的信息，捕捉时间序列中的顺序依赖性。2⃣️参数共享：处理每个元素的单元cell是相同的，减少了模型的参数数量，更好地泛化。看似是一个词一个词按序处理，但其实是拿整个句子整体在训练网络。
  • RNN总结：一个能处理序列数据、记忆过去信息、并考虑时间序列中的上下文依赖关系的神经网络。RNN在保持相对较少的参数数量的同时，通过在序列的每个时间步共享同一组权重，以循环的方式来处理数据。在机器学习中，RNN常被应用于语言处理、时间序列分析和其他需要考虑数据时序性的任务中。
  • RNN缺点：1⃣️靠前的词特征，传递到最后影响力很小，于是全句的特征更集中在后半句。这个问题在LSTM里加了个记忆力机制。2⃣️词词间特征更关注相邻的，跨词的关系表达不强。这个问题在transformer的attention机制解决。3⃣️训练效率，只能一个词一个词串行的搞，不好并行。这个问题同样在transformer中通过掩码机制解决。
  • transformer：Q K V注意力机制，站在了整个句子的维度、mask机制可以让transformer并行训练，大大提高训练效率、encoder和decoder。
  • transformer机制：1⃣️并行计算： Transformer 允许对序列数据的整个输入进行同时处理，消除了像RNN这样的模型在处理每个序列时所需的时间步长。2⃣️自注意力机制（Self-Attention）： Transformer通过自注意力，可以同时考虑输入序列中所有位置的词之间的关系，从而允许模型捕捉序列内全局的依赖性。3⃣️多头注意力（Multi-Head Attention）： 通过多头注意力，模型可以在不同的子空间中捕捉复杂的关系，提高了信息提取的能力。本质上和CNN的通道是一个逻辑，就是想以不同的抽取器得到同一个对象的不同视角的特征。4⃣️总结而言，Transformer机制通过自注意力和多头注意力实现并行化和全局化的处理，结合位置编码、前馈
  • 对模型的理解：模型本质上是由一系列矩阵（权重）构成的，这些矩阵通过线性和非线性运算相互连接。模型通过将输入数据（无论是文本、图像还是其他类型的数据）使用嵌入技术embedding转换为数值型特征向量。然后，这些数字化的特征通过模型中的矩阵进行前向传播，最终产生一组预测输出，通常为分类任务概率分布。通过与实际值的比较计算损失（差异），使用反向传播算法调整模型矩阵中的权重从而不断优化模型性能。
  • 对CNN、RNN、Transformer的理解：1⃣️CNN卷积神经网络：处理具有网格状拓扑结构如图像的模型，本质上就是拿很多个不同类型的（Channel通道）的放大镜（Convolution卷积核）去目标事物上扫描，从而发现更多的局部特征。逐层深入，选择并强化最重要的特征。通过池化层简化特征集，并选择最显著的特征。经过一系列卷积和池化操作后，CNN 在其最后阶段利用全连接层计算分类预测的概率。2⃣️RNN循环神经网络：处理序列数据的模型，本质就是一个词一个词的投喂给同一模型，从而能更好的发现词和词之间的顺序、关联性等特征，在NLP语言处理的场景上很合适。3⃣️ Transformer：通过mask掩码的机制解决了RNN的串行计算问题，通过注意力机制解决了CNN、RNN只能发现局部特征的限制。前者大大加速了模型的训练效率，后者通过全局视角的注意力机制大大提高了模型在NLP处理的精准度。
  • 模型参数和超参数：模型参数是在训练数据上学习的变量，例如神经网络中的权重和偏置，它们在学习过程中通过数据不断更新和优化。超参数是在训练开始前设定的，在训练过程中保持不变，包括：学习率、批次大小、迭代次数、神经网络的层数和大小、正则化项强度等。

数据处理

  • parquet：一种列式的开源存储格式，用于大规模数据处理和分析，拥有高效的存储和读取性能，支持多种高效压缩算法，广泛应用于大数据生态。相比行式存储，列式存储优点：相同类型的数据存储在一起更容易高效压缩，对于只需要读取部分列的查询可以减少IO。与hadoop、spark、hive等兼容。用pandas就可以读取，df = pd.read_parquet(file_path)。
  • hugging face是开源社区，ModelScope魔搭是阿里AI模型社区。
  • MinHash 是一种高效的算法，用于估计两个集合的相似度（Jaccard 相似度）的高效算法，尤其适用于海量数据处理。Jaccard 相似度 = 两个集合交集的大小除以并集的大小。但是当集合非常大时，直接计算交集和并集的成本很高，尤其是当集合数量很多时。MinHash：通过哈希函数将集合压缩成一个固定长度的签名，从而快速估计 Jaccard 相似度。步骤：选择k个哈希函数，对集合中的每个元素应用k个的哈希函数，记录每个哈希函数生成的最小哈希值，构建k长度的签名矩阵，然后通过比较签名矩阵中的签名向量来高效估计各集合之间的相似性。
  • ngram：指的是文本中的连续n个项目（如字符、单词）的序列
  • 语言模型是用来计算一段文本的概率。有统计语言模型和神经网络语言模型，对于实时性要求高的应用，通常会使用统计语言模型。无法往前看所有单词，就看固定数量的单词，假设每个词只和它前 n-1 个词相关，这就是n-gram。n越大，更能体现出句子信息，但是模型参数会指数级增大，一般传统的语音识别中，会经常使用三元语言模型。
  • cc：一个包含所有公共网页的大规模数据集，开源的。
  • 大模型数据工程：采集处理所有风格的研发资产（文本、图像、知识图谱、数据库…），将其形成预训练语料或者指令微调数据集。并针对不同的资产格式或者研发场景任务设计详细的训练数据以及分层知识库。需要确保数据消费的安全性和可追溯性，包括数据集采集、标注、清洗、评估。
  • 训练数据包括：通用文本：网页，如CommonCrawl，数据量大，使得 LLM 能够获得多样化的语言知识并增强 LLM 的泛化能力；多轮对话文本，如公共对话语料，增强 LLM 的对话能力；书籍。专用文本：多语言文本、科学文本、百科、论文、代码。
  • 数据预处理流程：采集/采购/合成的rawdata原始数据，进行解析，清洗（启发式规则、模型质量分筛选、去重、去污、去毒、隐私打码），标准化为processdata，质量评估，ID化（用于将文本分解为词或子词的组合，使机器更好地理解和分析文本），上架上云为Trainabledata。
  • 数据去噪：优点：提高数据准确性和一致性，减少数据中的干扰因素，提升模型的性能，增强模型泛化能力，提升训练效率。方法：启发式基于规则的数据清洗（例如URL过滤、页面长度过滤、去除特殊字符等）、基于模型的高质量文本筛选（例如使用fastText二进制分类器进行模型打分）。
  • 数据去毒：优点：毒性过滤旨在去除数据集中不需要的有毒文本（诸如涉黄、涉政、涉赌等敏感信息），减少偏见和歧视性内容，降低模型在实际应用中产生不当输出的风险。方法：对数据进行扫描打标，其中有用到小模型、Bert模型进行识别，也有使用关键字进行识别。
  • 数据去重：优点：重复数据删除有利于缓解记忆、避免训练-测试重叠、提高训练效率，同时保持模型困惑。有助于平衡模型的记忆和泛化。方法：md5去重、ngram去重，将文本分割成连续的ngram序列来识别和消除重复内容、全局去重等方式，去掉重复数据。DCLM中还用到MinHash算法进行文档级别去重、Bloom过滤器进行文档和段落级别去重。
  • 数据去污：优点：去除与测试集和打榜数据集重叠的样本。这是为了确保模型在测试阶段能够准确地评估其性能。方法：DCLM中去污包含移除与测试集重叠的训练样本，例如移除DCLM-BASELINE中包含MMLU问题及其选项的文档。
