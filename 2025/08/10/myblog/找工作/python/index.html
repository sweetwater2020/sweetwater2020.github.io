那些年背过的面试题之Python

Posted on 2025-08-10 Edited on 2025-12-05 In 那些年背过的面试题 Views:

Python基础

  • Python 的装饰器：一种函数，它可以接受另一个函数作为输入，并修改其行为，而不需要修改该函数的源代码。通常用于引入横切关注点（如透明地添加功能、日志记录、缓存等），从而提高代码的可重用性和可维护性。

  • 装饰器本质是个函数，接收另一个函数作为参数，返回一个新函数。

  • Python 中的迭代器和生成器：

    迭代器是一个可以被 for 循环遍历的对象，必须实现 iter() 和 next() 方法。

    生成器是一种特殊的迭代器，它是通过函数def和 yield 关键字定义的，能够“懒惰地”生成数据，自动实现迭代器协议。当在函数中调用 yield 语句时，函数会被暂停，一个值被返回给调用者，并保留函数的状态，以便在下次调用时从该状态恢复。生成器代码更简洁、内存更节省，适合处理大量数据，如文件逐行读取。所有生成器都是迭代器。

    生成器的好处是它可以迭代大型数据集而显著减少内存使用。

  • Python 的虚拟环境：是一个独立的 Python 运行环境，用来隔离不同项目的依赖包，避免版本冲突。内置了 venv 模块来创建虚拟环境。或者用conda。

  • Python的lambda：lambda 是 Python 中的一种匿名函数，用于临时定义一个小型、单用途的函数。用于定义简单的、只有一行表达式的函数，而不需要用 def 关键字命名。add_two_numbers = lambda x, y: x + y

  • python数据结构：列表（list）、元组（tuple）、字典（dict）和集合（set）。列表（list） 是有序、可变的集合，支持增删改查；元组（tuple） 是有序、不可变的，常用于固定数据；字典（dict） 存储键值对，查找高效，适用于映射关系；集合（set） 是无序不重复元素集，适合去重和成员判断。

  • list和tuple：list 是可变的，tuple 是不可变的。如果你的数据不会变，比如配置项、坐标点，就用 tuple，更安全也更快一点；如果要增删改，比如动态收集结果，就用 list。

  • python的collections模块：比内置类型更高级的容器类型。namedtuple：带字段名的元组，可通过属性访问元素。deque：双向队列，支持在首尾高效添加和删除，适用于队列、栈等场景。Counter：用于统计元素出现次数。

  • python的is和==：== 比较两个对象的值是否相等；is 比较它们是否是同一个对象（内存地址相同）

  • Python 中的继承和多态：继承是指子类可以复用父类的方法和属性。多态表示比如父类有 speak() 方法，子类 Dog 和 Cat 可以各自实现不同的行为。

  • python中的__init__、__str__、__repr__：__init__：构造方法，用于初始化对象属性。__str__：定义 str(obj) 或 print(obj) 时的字符串表示，面向用户。__repr__：定义 repr(obj) 时的“官方”字符串表示。

python常用库

  • python内置模块：

os：用于与操作系统交互，如文件/目录操作（os.listdir、os.remove）、路径处理（os.path.join）、环境变量（os.environ）等。

sys：与解释器相关，如命令行参数（sys.argv）、模块搜索路径（sys.path）、程序退出（sys.exit）。

re：正则表达式处理，常用 re.match、re.search、re.findall、re.sub 进行字符串匹配与替换。

datetime / time：用于日期时间处理与时间戳操作，datetime 更偏向日期时间对象，time 偏底层与时间戳、sleep。

math：提供数学函数，如 sqrt、ceil、floor、sin、log 等，多为 C 实现，性能较高。

  • requests：用于发送 HTTP 请求：response = requests.get("https://httpbin.org/get")

  • numpy：数值计算基础库，高效的多维数组与矩阵运算：arr = np.array([1, 2, 3, 4])

  • pandas：数据分析和处理，DataFrame用于结构化数据操作：df = pd.read_csv('data.csv')

  • matplotlib：数据可视化，用于绘图：plt.plot(x, y, label="sin(x)")

  • TensorFlow / PyTorch：度学习框架，用于搭建和训练神经网络。torch.cuda.is_available()。torch.no_grad() 临时关闭梯度计算。

  • fastText：Facebook开源的一个高效的自然语言处理库，可进行文本分类、分词、语种识别等：tokens = self.fasttext.FastText.tokenize(text)、保存和加载模型fasttext.load_model、model.save_model

  • nlkt：自然语言NLP库，可进行分词：from nltk.tokenize import word_tokenize, sent_tokenize；print(sent_tokenize(text))。可去除停用词。可进行情感分析sentiment。

  • jieba：开源的中文分词库，精确模式分词：seg_list = jieba.cut(text, cut_all=False)，还可以进行关键字提取、词性标注等。

  • transformers：Hugging Face开发维护的基于transformer架构的python库，提供数千种预训练模型（BERT、GPT、T5），可进行文本分类、命名实体识别、文本生成等。加载模型：tokenizer = AutoTokenizer.from_pretrained()。BertForSequenceClassification用于文本分类任务。

  • vllm：为LLM设计的高性能推理框架，提升推理速度、降低显存占用、支持高并发请求。PagedAttention技术，类似操作系统的分页内存，优化注意力机制中的KV存储。比 Hugging Face Transformers 快 24 倍以上。

  • fastapi：高性能的web框架，专为构建API设计。

python并发编程

  • python的GIL：全局解释器锁，是 CPython 里的一个机制。它是一种为了确保在同一时间只有一个线程可以执行 Python 代码的机制。这个锁主要是出于安全目的的考虑，Python 在管理内存和解析器的过程中依赖于很多全局数据结构。使用 GIL，Python 能够避免多个线程同时访问和更改这些结构，从而保证线程安全。

  • python多线程编程：使用 threading 模块实现，适用于 I/O 密集型任务（如网络请求、文件读写）因为等 I/O 的时候会释放 GIL。但受限于 GIL（全局解释器锁），同一时刻只能有一个线程执行 Python 字节码，因此 不适合 CPU 密集型任务，无法同时在多个CPU内核上并行运算。 真要并行算，一般用 multiprocessing 或者用 async/await。

    创建线程：t1 = threading.Thread(target=worker, args=("A",))

    启动线程：t1.start()

    等待线程完成：t1.join()

  • python多进程：multiprocessing模块，支持多进程编程。每个进程都拥有独立的Python解释器和内存空间，它们之间不会相互受GIL影响。多个进程就能被操作系统分配到不同CPU核心上，实现真正的并行运算。 p = multiprocessing.Process(target=compute_square, args=(num,))

  • python异步编程：基于 async / await 关键字和 asyncio 事件循环实现，适合高并发的 I/O 密集型应用，单线程中实现并发，利用“等待时间”做别的事，避免阻塞。async def 定义一个协程函数，await 等待一个异步操作完成，asyncio 提供事件循环（event loop）来调度协程。常用库有 httpx、aiohttp，现代框架如 FastAPI 天然支持。但不适合 CPU 密集型任务，且需要避免在协程中使用阻塞操作。异步不是“更快”，而是“更忙”——它让程序在等待时也不闲着，把每一秒都用到极致。

  • python并发编程总结：

    1、threading 提供多线程支持，适合 IO 密集型任务（如网络、磁盘 IO）。但由于 CPython 的 GIL（全局解释器锁），同一进程内同一时刻只允许一个线程执行字节码，所以无法利用多核并行。t = threading.Thread(target=func); t.start()

    2、multiprocessing 通过多进程绕过 GIL，每个进程有独立的 Python 解释器和内存空间，可充分利用多核 CPU，适合 CPU 密集型任务。需要通过 Queue、Pipe、Manager 等实现进程间通信，开销比线程大。p = multiprocessing.Process(target=func); p.start()

    3、asyncio 提供基于事件循环的协程模型，使用 async/await 语法实现单线程高并发 IO，适合大量网络请求、爬虫、异步服务等。底层利用非阻塞 IO + 事件循环调度协程执行。asyncio.run(main())

  • python中的锁：threading.Lock，确保同一时刻只有一个线程执行某段代码（临界区）。

    创建一个锁：lock = threading.Lock()。

    在访问共享资源前加锁：lock.acquire()。

    使用完后释放锁：lock.release()。

    推荐使用with lock:语句，自动加锁/释放。

  • python中的线程池：concurrent.futures中的ThreadPoolExecutor，指定最大线程数。submit() 提交任务、as_completed() 获取结果。 “ThreadPoolExecutor 主要有四个参数：max_workers 控制并发度，thread_name_prefix 便于调试，initializer 和 initargs 用于线程初始化。 导入模块：from concurrent.futures import ThreadPoolExecutor

python网络编程

  • python中http请求：使用第三方库 requests，response = requests.get(“https://…”)。也可以用python内置库urllib，但是代码冗长，错误处理麻烦，不支持连接池。
  • python异步请求：httpx 是 requests 的异步增强版：async with httpx.AsyncClient() as client: response = await client.get(url)。也可以用aiohttp发起异步请求。
  • python的web开发：主要使用 Django 和 Flask 等框架。Django内置 ORM、模板引擎、表单、认证、后台管理等，适合中大型项目、后台管理系统、企业级应用。Flask 是一个轻量级微框架，核心非常小，只提供路由、请求/响应等基础能力，其他如 ORM依赖第三方扩展，适合小项目、微服务、API 服务。

python测试

  • python测试：

unittest 是标准库自带的 xUnit 风格框架，使用类来组织测试用例，提供丰富的断言方法（如 assertEqual、assertTrue 等），支持 setUp / tearDown 进行测试前后初始化和清理。适合对测试结构要求比较规范、优点是“零依赖”，随 Python 一起安装。

pytest 是第三方框架，特点是语法更简洁、上手更快：不强制使用类，直接定义 test_ 开头的函数即可，通过 assert 即可断言。它有强大的 fixture 机制，用于数据准备和依赖注入，配合丰富的插件生态（如覆盖率、失败重跑、并行执行）非常适合中大型项目。实际工程中 pytest 使用更普遍。

Django

Django 是一个用 Python 编写的高级 Web 框架，倡导“开箱即用”和快速开发。它内置了 ORM（对象关系映射）、URL 路由、模板引擎、表单处理、用户认证和强大的后台管理（Admin）等核心功能，能有效处理 Web 开发中的常见任务。Django 遵循 **MVT（模型-视图-模板）**设计模式，结构清晰，代码复用性高。它注重安全性，能自动防范 CSRF、XSS 等常见攻击。凭借其完备的生态系统和严谨的设计，Django 非常适合构建数据驱动、安全可靠的中大型 Web 应用，让开发者更专注于业务逻辑的实现。

使用 Django 开发的步骤：1. 安装：pip install django。2. 创建项目：django-admin startproject mysite，生成项目骨架。3. 创建应用：python manage.py startapp myapp，Django 鼓励功能模块化。4. 定义模型：在 models.py 中用 Python 类定义数据结构，Django ORM 映射到数据库。5. 注册应用：将应用名添加到 settings.py 的 INSTALLED_APPS 中。6. 设计 URL：在项目和应用中配置 urls.py，将 URL 路由到视图。7. 编写视图：在 views.py 中处理请求并返回响应（如渲染模板）。8. 创建模板：在 templates 目录下编写 HTML 模板。9. 迁移数据库：makemigrations 生成迁移文件，migrate 同步模型到数据库。10. 运行：python manage.py runserver 启动开发服务器。

在Docker内运行：编写 Dockerfile 定义Python环境、安装依赖（包括Django）；创建 docker-compose.yml 配置Web服务和数据库（如PostgreSQL）；将代码复制到镜像；暴露端口（如8000）；使用 docker-compose up 构建并运行容器，Django应用即在隔离环境中启动。

Fastapi

FastAPI是Python Web框架，专为快速构建RESTful API而设计，支持类型注解、自动生成交互式文档，并具备异步性能。

FastAPI 通过 StreamingResponse 实现流式输出，适合实时返回数据（如 AI 回复）。使用 yield 关键字将函数变成生成器，在其中逐段产出数据，每次 yield 发送一部分，不占用大量内存。yield 类似“暂停并返回”，下次从断点继续。

  • python中fastapi如何实现流式输出

    FastAPI是Python Web框架，专为快速构建RESTful API而设计，支持类型注解、自动生成交互式文档，并具备异步性能。

    FastAPI 通过 StreamingResponse 实现流式输出，适合实时返回数据（如 AI 回复）。使用 yield 关键字将函数变成生成器，在其中逐段产出数据，每次 yield 发送一部分，不占用大量内存。yield 类似“暂停并返回”，下次从断点继续。

  • FastAPI：一个现代、高性能的 Python Web 框架，用于构建 API。支持异步处理、流式输出，核心优势包括：自动生成功能完备的交互式 API 文档、强类型提示 + 请求数据校验。用于快速开发安全、可维护的后端服务。

PyTorch 和 TensorFlow

更常用 PyTorch，因为它动态图（eager execution）写起来像写 Python，调试方便，特别适合研究和快速实验。TensorFlow 2.x 也支持 eager 模式了，但在部署、生产环境（比如 TFServing、TensorRT）上生态更成熟。现在两者差距不大，但 PyTorch 在学术界更主流。

“PyTorch 做实验，TensorFlow 跑生产” —— 但现在界限模糊了，关键看团队技术栈和具体需求。

怎么保存和加载 PyTorch 模型

有两种方式。一种是只存参数（推荐）：torch.save(model.state_dict(), 'model.pth')，加载时先建好模型结构再 load_state_dict()；另一种是直接存整个模型（不推荐，依赖代码结构）。生产部署一般用第一种，灵活又安全。

怎么防止过拟合

常用方法包括：加 Dropout、权重衰减（L2 正则）、早停（early stopping）、数据增强（比如图像旋转裁剪）、用更小的模型。我在项目里经常组合用：比如图像分类任务，加 RandAugment + Dropout + ReduceLROnPlateau + early stopping，效果不错。
